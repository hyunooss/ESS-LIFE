# ESS 배터리 수명 예측

초기 100사이클의 기록으로 배터리의 총 수명(`cycle_life`)을 예측하는 회귀 프로젝트입니다.  
사전 EDA를 바탕으로 Feature와 모델을 비교하고, Batch 2 성능과 논문 참고값 9.1%의 차이를 해석합니다.

## 프로젝트 개요

- 데이터셋: MIT–Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터: Batch 1 (`2017-05-12`), 원본 46개 중 EDA 분석군 36개
- 평가 데이터: Batch 2 (`2018-02-20`), 수명 라벨이 있는 39개
- 태스크: **Regression — 총 Cycle Life 예측**
- EDA: Batch 1·2·3의 분포·열화·충전 조건을 비교합니다.
- 추가 모델 평가: Batch 3 (`2018-04-12`)는 선택 사항이며 기본 모델 실행에서는 제외합니다.

예측 단위는 배터리 셀 1개입니다. 초기 100사이클 이후의 잔여 수명이 아니라 제공된 총 수명을 예측하며, `2018-04-03 varcharge` 파일은 사용하지 않습니다.

python -m jupyterlab 1_eda.ipynb

## EDA

[`1_eda.ipynb`](1_eda.ipynb)에서 데이터 점검 → EDA 1~5 → Feature·모델 설계 → 검증 계획 순서로 확인할 수 있습니다.
각 분석에는 계산 코드, 그래프·표, 확인한 점과 모델 전략을 함께 정리했습니다.
큰 충전 시간의 민감도 분석과 주요 수치의 재현 점검도 포함합니다.

아래는 사전 EDA의 핵심 발견입니다. 분포는 B1 원본 46개를 사용했으며, Feature 관계는 B1 분석군 36개·B2 39개·B3 44개를 기준으로 확인했습니다.

- **Cycle Life 분포:** 배치별 중앙 수명은 858.5·472.0·1,005.5사이클이며, B2의 500사이클 미만 비율은 71.8%입니다. B1 분석군의 수명은 534~1,074사이클이므로 짧은 수명을 길게 예측하는지 확인해야 합니다.
- **열화 곡선 분석:** 배치별 대표 셀에서 후반 용량 감소가 빨라졌고 변화 후보는 594·335·807사이클이었습니다. 배치당 한 셀의 탐색 결과이며 B3 후보는 탐색 경계에 있어 knee로 확정하지 않았고, 전체 수명에서 찾은 변화 시점은 입력에서 제외했습니다.
- **ΔQ(V) 곡선 분석:** 실제 100번과 10번의 차이를 같은 1,000점 전압 격자(2.0~3.5 V)에서 계산했으며, 로그분산과 수명의 Pearson 상관은 배치별 −0.827·−0.902·−0.702였습니다. 공통된 음의 관계를 근거로 기본 Feature로 사용하되, 상관계수를 예측 정확도로 해석하지 않았습니다.
- **충전 속도(C-rate)와 수명의 관계:** B1에서 C1=8C·C2=3.6C가 같아도 전환 SOC가 15%와 35%인 정책의 평균 수명은 1,008.5와 607.5사이클로 달랐습니다(각 2개). 표본이 적어 인과관계를 단정하지 않고 C1·전환 SOC·C2를 함께 비교했습니다.
- **상관관계와 중복 정보:** B1에서 평균·최고 온도의 상관은 0.95, ΔQ 로그분산·최솟값의 상관은 −0.99였습니다. B2 충전 시간과 수명의 상관은 평균 0.087, 중앙값 −0.918로 달라, 큰 기록을 임의 삭제하지 않고 평균·중앙값을 B1 CV에서 비교했습니다.

## Modeling

### Feature 엔지니어링 전략

| Feature                  | EDA 근거와 구현                                                       |
| ------------------------ | --------------------------------------------------------------------- |
| ΔQ 로그분산              | `log10(var(Qdlin100 − Qdlin10, ddof=0))` 단독부터 시작                |
| 초기 용량 변화·충전 시간 | `QD100−QD2`, 2~100사이클 충전 시간의 평균 또는 중앙값 추가            |
| 온도·충전 정책           | 평균 온도와 C1·전환 SOC·C2를 함께 추가; 중복이 큰 최고 온도는 제외    |
| 용량 기울기·IR           | 2~100사이클 기울기, 유효 IR 평균을 단계적으로 추가하여 개선 여부 확인 |

용량·IR·충전 시간의 0 이하 값과 사전 EDA에서 확인한 고립된 용량 스파이크는 해당 값만 결측 처리합니다.  
100분 초과 충전 시간은 유지합니다.
결측 대체와 표준화는 각 학습 fold 안에서만 수행하며, 정답·마지막 용량·전체 기록 길이·100사이클 이후 값·knee·배치 및 셀 ID는 입력에 넣지 않습니다.

### 모델 선택 및 근거

| 후보 모델         | 비교 이유                                   |
| ----------------- | ------------------------------------------- |
| Linear Regression | 적은 Feature의 선형 관계를 기준으로 확인    |
| Ridge             | Feature 간 중복을 규제로 완화               |
| Random Forest     | 비선형 관계를 비교하고 과도한 복잡도를 제한 |
| SVR (RBF)         | 표준화 후 곡선 관계를 비교                  |

- 최종 모델은 **SVR**, Feature는 `F1_DeltaQ`입니다.
- 입력 1개: `dq_log10_variance`
- 최저 CV MAPE와 1%p 이내인 후보 중 Feature가 적은 구성을 우선하고, 다음으로 CV MAPE를 비교했습니다.
- 최종 설정: `C=1000.0, epsilon=10.0, gamma=0.01`
- B1 36개 중 학습/CV는 29개, hold-out은 7개이며 B2 평가 대상은 39개입니다.

<!-- MODEL_RESULT_END -->

B1의 정책 그룹을 유지해 학습/CV와 hold-out을 분리하고, 학습 부분에서 5-fold CV를 진행했습니다(`random_state=42`). 최저 CV MAPE와 1%p 이내인 후보에서 Feature 수가 적은 구성을 우선하고, 다음으로 CV MAPE를 비교합니다. 설정을 고정한 뒤 hold-out을 평가하고, B1 분석군 전체로 재학습한 후 B2를 평가합니다.

Random Forest는 B1 OOF 예측에서 각 fold의 학습 수명 최솟값보다 짧은 검증 셀의 과대 예측도 보조 점검했습니다. B1에 500사이클 미만 셀이 없어 해당 구간 전체를 검증한 결과는 아닙니다.
